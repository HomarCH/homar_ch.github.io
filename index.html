Proyecto API Pokédex

Pokédex de consumo Api que muestra Pokémon y su información. Utilicé la API de pokeapi.co para la información de cada Pokémon.
En este programa quise explorar más en estilizarlo con una estética alusiva a Pokémon y a el Pixel-art, teniendo en cuenta también la paleta de colores.

Proyecto Keso Pastelería

E-commerce para una pastelería local.

Proyecto integrador realizado en equipo, en el que implementamos conocimientos tanto para el Front-end como el Back-end, así como un flujo de trabajo utilizando SCRUM, GitHub y Kanban, en el cual también hicimos intercambio de roles para involucrarnos en distintos aspectos del proyecto.

Personalmente disfruté más la parte del Front-end, donde hicimos uso de herramientas como Figma y Bootstrap, para el diseño de cada página.

Enlace a Keso Pastelería (Repositorio).

Proyecto de Hackatón: SkateBros

E-commerce para una tienda de patinetas.
Este proyecto fue el objetivo de un Hackatón, el cual consistió en trabajar en equipo para crear una E-commerce para una tienda de deportes, sólo que tomamos la decisión de orientarla al skateboarding, por lo que le dimos una imagen adecuada a ese deporte.
Este fue mi primer Hackatón, actividad que me dejó una experiencia gratificante y que también me generó mucho conocimiento.



Enlace a SkateBros.
